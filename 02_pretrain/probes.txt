# Stage 02 — inference probe set
#
# Input to 02_pretrain/eval_probes.py. Edit freely, then re-run the eval.
# Track A's corpus is tiny; these probes are for *seeing what the models
# learned and how they differ*, not a leaderboard.
#
# Syntax
#   '#' starts a comment; blank lines are ignored.
#   A section header is [name]. Four sections, one per probe type:
#
#   [continuation]  one bare prompt per line. Free generation, sampled
#                   across the temperature dial — what the model sounds
#                   like, and how raising temperature dissolves it.
#   [cloze]         'prefix <TAB> gold'. The model is scored on how
#                   surprised it is by the gold span (bits-per-character,
#                   lower = better) — an automatic, tokenizer-fair metric.
#   [qa]            one naked question per line. A base model has never
#                   seen the question->answer form, so it rambles instead
#                   of answering — seeing that failure once is the point.
#   [memorize]      'prompt <TAB> reference'. Greedy-decode from the prompt
#                   and measure the longest verbatim run shared with the
#                   reference (the real training text). A long shared run
#                   means the model memorised the archive.
#
#   In [cloze] and [memorize] the two fields are TAB-separated, and a
#   literal \n in either field becomes a newline (so a multi-line prompt
#   can sit on one line).

[continuation]
罗德岛
源石
凯尔希
感染者

[cloze]
# Verbatim corpus phrasings — the gold really occurs in the training text,
# so a low score means the model learned the corpus.

# story corpus rarely uses; tests whether the association survives a rephrase.
