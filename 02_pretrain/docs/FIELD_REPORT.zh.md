# 候选模型评估报告

> **罗德岛医疗项目 · 候选模型评估报告**
> Rhodes Island Medical Project — 内部评估
> 权限：公开 · 对象：九台 Track A 语言模型 · 阶段：02

*这是 Stage 02 推理探针结果的一份「带入设定」的写法。外壳是明日方舟，外壳
之下的每一个数字都是真实的。干涩的训练数据表见 [`RESULTS.md`](RESULTS.md)；
英文版报告见 [`FIELD_REPORT.md`](FIELD_REPORT.md)。本报告的全部内容可复现：*

```bash
.venv/bin/python 02_pretrain/eval_probes.py        # 种子 1337，读取 probes.txt
```

## 任务简报

九名候选者被培养来**复述档案**——读懂罗德岛的记录，并把它续写下去。每一名
都是从零开始、在同一份内部语料上训练的（Stage 00 的 `train` 划分：约 600 万
token，一份**极小**的档案）。没有人指望他们成为强干员；本次评估的意义在于看
清他们**彼此有何不同**、**会在哪里失败**——并为另一个项目的老兵（Track B 的
Qwen3-0.6B）划下基准线，他稍后会走完同样的考核站点。

候选者沿三条轴线相互区别——体量、词表、以及一次能持有多宽的上下文窗口：

| 候选者       | 构型                 | 一句话 |
|--------------|----------------------|--------|
| `tiny_32k`   | scale tiny · 11.7M   | 新兵——碎片流利，整体失焦 |
| `small_32k`  | scale small · 23.4M  | **标准候选者**——本次评估的中心 |
| `large_32k`  | scale large · 42.3M  | 偏才——把档案背得最熟，却最不会举一反三 |
| `small_8k`   | vocab 8k · 14.0M     | 以更小的碎片阅读档案 |
| `small_16k`  | vocab 16k · 17.1M    | 不声不响的最高分 |
| `ctx_256`    | window 256           | 记忆短，但操练次数最多 |
| `ctx_1024`   | window 1024          | 桌面更宽，操练更少 |
| `ctx_2048`   | window 2048          | 桌面很宽，只练了四分之一 |
| `ctx_4096`   | window 4096          | 桌面最宽——却几乎没时间练 |

以下是五个考核站点。

---

## 站点一 · 自由陈述

*给候选者一个词，任其往下说。*（采样，温度 0.8。）

无一例外，每名候选者开口就复现档案的**外形**——故事文件的 `<章节>` /
`<正文>` 标签骨架——并填入局部说得通的罗德岛对话。`small_32k`，提示词 `罗德岛`：

```
</活动名称>
<章节>
<章节名称>罗德岛舰船（幕间）</章节名称>
<章节简介>罗德岛一行在工程方面，凯尔希正需要博士提供罗德岛的技术支持。</章节简介>
<正文>
10:10 P.M. 天气/阴
罗德岛本舰，工程部
可露希尔: 可露希尔，你在后面等着？
```

外形无可挑剔；内容却在原地打转、不断重复（`罗德岛`……`罗德岛`……）。这正是
站点一的结论：**小模型会先学会一份语料的「文体」，远早于学会「表达意义」。**
档案的结构很廉价——同样的几个标签重复了 1,299 次——所以每名候选者都能拿下。
意义很昂贵，而 600 万 token 买不到多少。

两名窗口最宽的候选者连外形都撑不住。`ctx_4096`，提示词 `凯尔希`：

```
:                                            （      她。
佐菲娅: ......
索娜: （: ——
玛莉娅: 啧
```

这不是风格选择——这是一名根本没训练完的候选者（见站点三与 `RESULTS.md`）。
请记住这一点。

## 站点二 · 源石活性测试

*「温度」这个旋钮决定候选者在每个词上下多大的赌注。用设定的话说，它就是源石
暴露量：少许令人锐利，过量令人崩解。* 一名候选者（`small_32k`）、一个提示词
（`罗德岛`），关闭 top-k，旋钮从低扫到高：

**温度 0.2 ——「教条」。** 安全到卡死：

```
<章节简介>罗德岛一行小队，罗德岛一行小队小队，带领小队小队小队小队小队，
带领小队小队小队小队小队小队小队。
```

**温度 0.7 ——「标准战备」。** 工作区间——多样、勉强切题。

**温度 1.0 ——「亢奋」。** 富有想象、四处游荡，但仍合语法。

**温度 1.4 ——「失稳 · 源石扩散」。** 候选者结晶成噪声——连字都不再成词：

```
<章节名称>这玩意暂时不敢号称的军事沉重在于罗德岛不会遇到什么这么小恹那当然
聒噪也就只有知道啦的铁的城市的孩子正在痛快一杯趴在那里你们是一样的~
```

**结论。** 温度只是「可读性—多样性」旋钮，仅此而已。工作区间约为
0.7–1.0；低于此候选者会打转，高于约 1.2 它的输出便像未经治疗的感染一样扩散。
设定里的隐喻不是装饰——它就是机制本身：两者都是一个受控过程滑向失控过程。

## 站点三 · 档案填空

*唯一计分的站点。* 给候选者一个句子的前缀，其真实结尾已知，按它对真相有多
**惊讶**来评分——绝不采样——单位是**每字符比特数**（越低越好）。每字符比特数
在词表不同的候选者之间是公平的，因此这个数字稍后也能干净地与 Track B 对比。

| 候选者       | 平均比特/字符 | 解读 |
|--------------|---------------|------|
| `small_16k`  | **3.820**     | 不声不响的冠军 |
| `small_32k`  | 3.880         | 标准候选者，紧随其后 |
| `small_8k`   | 3.915         | — |
| `tiny_32k`   | 3.963         | 新兵，不出意料地是「标准三人组」末位 |
| `large_32k`  | 4.054         | **偏才得分*低于* `small`** |
| `ctx_256`    | 4.057         | 窗口最短，无妨 |
| `ctx_1024`   | 4.153         | — |
| `ctx_2048`   | 4.910         | — |
| `ctx_4096`   | 5.272         | 桌面最宽，得分最差 |

两项结论，都已在训练数据表里见过，如今在留出句子上得到证实：

- **偏才过拟合了。** `large_32k` 容量最大、*训练*分数最好，可在这些探针上它
  却落到了 `small_32k` *后面*。在一份 600 万 token 的档案上，多出来的容量被
  用去**背诵**，而非**理解**。
- **宽窗口候选者从未练完。** `ctx_2048` 与 `ctx_4096` 大幅落后——不是因为宽
  窗口本身不好，而是在固定的 token 预算下，窗口越宽，训练操练次数就越少
  （`ctx_4096` 仅 1,000 次，`ctx_256` 有 16,000 次）。他们是训练不足，不是
  设计失误。

## 站点四 · 标准问询

*向候选者提一个直白的问题，期待它作答。* 它不会。被问到
**「阿米娅在罗德岛担任什么职务？」** 时，`small_32k` 的回答是——一份
**临床诊断分析**：

```
临床诊断分析:造影检测结果显示，该干员体内脏器轮廓清晰，未见异常阴影……
【体细胞与源石融合率】0%
干员阿米娅没有被源石感染的迹象。
```

它并没有误解问题。它根本没看见过「问题」。档案里只有故事剧本和干员文件——而
且**完全没有问答对**。所以一个问号，对候选者而言只是一份干员文件不寻常的开
头，它便自动补全成它所知道的、最接近的那种档案格式。

`large_32k` 被问同一个问题，则东拉西扯到另一名干员的派遣上。**体量救不了这一
点。** 回答问题并不是一种「知道事实就会涌现」的能力——它是一种**习得的协议**、
一种轮流发言的格式，必须由**后续的训练阶段安装**（项目里的指令微调步骤——姑
且称之为「行为协议训练」）。本站点的存在，就是把这一处失败摆到无可争辩的位
置，好让那个阶段的必要性不再是一件见仁见智的事。

## 站点五 · 记忆核验

*把一份真实干员文件的开头交给候选者*——阿米娅的，截到 `<干员招聘文本>` 标签
为止——*看它是否能背出她真正的招聘语。* 真实文本是
`罗德岛公开领导人阿米娅，将与你并肩作战。`。贪心解码，所以这是候选者最有把握
的那一个答案。

每名候选者都产出了一句语法完美的招聘语——只是属于**错误的那个阿米娅**：

| 候选者      | 把阿米娅背成了…… | （她真正的头衔：公开领导人） |
|-------------|------------------|------------------------------|
| `tiny_32k`  | 罗德岛**狙击**干员阿米娅 | 狙击 |
| `small_32k` | 罗德岛**狙击**干员阿米娅 | 狙击 |
| `large_32k` | 罗德岛**先锋**干员阿米娅 | 先锋 |
| `small_8k`  | 罗德岛**医疗**干员阿米娅 | 医疗 |
| `ctx_256`   | 罗德岛**精英**干员阿米娅 | 「精英」 |

**结论——而且是个微妙的结论。** 候选者把招聘语的*模板*
（`罗德岛[职业]干员[姓名]，将[动词]……`）背得分毫不差——却没背下它的*内容*。
没有一个，连偏才 `large_32k` 也没有，复原出阿米娅真实的头衔。所以，早先在体量
轴上量到的「过拟合」，是对**模式与模板**的过拟合，而非对原文段落的过拟合。一
个小模型在一份小档案上，记住的是**档案的语法**，事实则靠现编。这与「大模型把
训练集一字不差地背了下来」是一幅不同的、也更诚实的图景。它没有。它背下的是
**模子**。

## 综合评定

**综合能力 — 推荐候选者 `small_32k`：**

```
文本结构  档案结构流利度        ★★★★☆   优良
局部通顺  局部通顺度            ★★★☆☆   标准
复读倾向  重复 / 打转倾向       ★★☆☆☆   异常
知识泛化  知识泛化能力          ★★☆☆☆   异常
问询协议  问询协议              ☆☆☆☆☆   缺失
源石耐受  温度稳定性            ★★★☆☆   标准
```

- **档案就是天花板。** 每一名 `small` 及以上的候选者都能流利地说出档案的文
  体，却几乎不持有任何可靠的知识。体量更大（`large`）会过拟合；窗口更宽
  （`ctx_2048+`）在固定预算下会让自己缺操练。极限来自这份 600 万 token 的语
  料，而非模型。
- **推荐候选者：`small_32k`**（或 `small_16k`，得分略胜一筹）。标准构型就是
  对的那个；更大、更宽都会倒退。
- **没有一名候选者可被问询。** 问答能力全员缺失——这是档案的构成所致，而非任
  何候选者之过。

**下一步。** 有两件，项目均已规划：通过指令微调安装问询协议（「行为协议训
练」）；并请来另一个项目的老兵——Track B 经过继续预训练的 Qwen3-0.6B——走完这
完全相同的五个站点，进行 Track A 一直在为之铺垫的正面对比。

*—— Stage 02 评估结束。探针集：[`../probes.txt`](../probes.txt)。*
