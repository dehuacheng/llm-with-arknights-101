## 任务简报

九名候选者被培养来**复述档案**——读懂罗德岛的记录，并把它续写下去。每一名
都是从零开始、在同一份内部语料上训练的（Stage 00 的 `train` 划分：约 600 万
token，一份**极小**的档案）。没有人指望他们成为强干员；本次评估的意义在于看
清他们**彼此有何不同**、**会在哪里失败**——并为另一个项目的老兵（Track B 的
Qwen3-0.6B）划下基准线，他稍后会走完同样的考核站点。

每名候选者都训练到自己的验证分数**不再下降**为止——恒定步长的操练加上**早停
机制**。所以每一名都在*自己的最高点*接受评估；没有人被拖过自己的巅峰，也没
有人被半途砍断。

候选者沿三条轴线相互区别——体量、词表、以及一次能持有多宽的上下文窗口：

| 候选者       | 构型                 | 一句话 |
|--------------|----------------------|--------|
| `tiny_32k`   | scale tiny · 11.7M   | 新兵——操练最久，却始终没追上 |
| `small_32k`  | scale small · 23.4M  | **标准候选者**——本次评估的中心 |
| `large_32k`  | scale large · 42.3M  | 偏才——最先到顶，与 `small` 同分 |
| `small_8k`   | vocab 8k · 14.0M     | 以更小的碎片阅读档案——**也读得最好** |
| `small_16k`  | vocab 16k · 17.1M    | 不声不响的中量级 |
| `ctx_256`    | window 256           | 记忆短，操练次数最多 |
| `ctx_1024`   | window 1024          | 桌面更宽，比标准微弱占优 |
| `ctx_2048`   | window 2048          | 桌面很宽，操练较少 |
| `ctx_4096`   | window 4096          | 桌面最宽——完成最晚，得分最差 |

以下是五个考核站点。

## 站点一 · 自由陈述

*给候选者一个词，任其往下说。*（采样，温度 0.8。）

无一例外，每名候选者开口就复现档案的**外形**——故事文件的 `<章节>` /
`<正文>` 标签骨架，或干员文件的 `<干员招聘文本>` / `<干员语音>` 骨架——并填入
局部说得通的罗德岛内容。`small_32k`，提示词 `罗德岛`：

```
</活动名称>
<章节>
<章节名称>合作（幕间）</章节名称>
<章节简介>博士收到来自罗德岛的委托，罗德岛决定用自己的方法让阿米娅收到罗德岛的合作。</章节简介>
<正文>
阿米娅: 这是......
阿米娅: 阿米娅，博士！
阿米娅: 抱歉......凯尔希医生，凯尔希医生，请叫我阿米娅吧。
```

外形无可挑剔；内容却在原地打转、不断重复（`阿米娅`……`阿米娅`……）。这正是
站点一的结论：**小模型会先学会一份语料的「文体」，远早于学会「表达意义」。**
档案的结构很廉价——同样的几个标签重复了 1,299 次——所以每名候选者都能拿下。
意义很昂贵，而 600 万 token 买不到多少。

窗口最宽的候选者**这次也撑住了外形**——上次评估它还做不到。`ctx_4096`，
提示词 `罗德岛`：

```
</活动名称>
<干员名称>
芙蓉</干员名称>

<干员招聘文本>
芙蓉，芙蓉，将身体托付给芙蓉。
```

合语法、上模板、却锁在了复读循环里。这名候选者在旧的「固定预算」设计下原本
是**根本读不懂的**——让他训练到*自己的*验证分数不再下降（而非在第 1,000 步
被砍断），就是修正这一处的关键。

## 站点二 · 源石活性测试

*「温度」这个旋钮决定候选者在每个词上下多大的赌注。用设定的话说，它就是源石
暴露量：少许令人锐利，过量令人崩解。* 一名候选者（`small_32k`）、一个提示词
（`罗德岛`），关闭 top-k，旋钮从低扫到高：

**温度 0.2 ——「教条」。** 安全到卡死：

```
<正文>
阿米娅: 博士，早上好。
阿米娅: 早上好，博士。
阿米娅: 早上好，博士。
阿米娅: 早上好，博士。
```

**温度 0.7 ——「标准战备」。** 工作区间——多样、勉强切题：

```
3:30 P.M. 天气/阴
罗德岛食堂
"华法琳，你在里面吗？"
近卫干员: 上次你说你抱怨过，这和我们刚过的一起过了好几圈……
```

**温度 1.0 ——「亢奋」。** 富有想象、四处游荡，但仍合语法。

**温度 1.4 ——「失稳 · 源石扩散」。** 候选者结晶成噪声——连字都不再成词：

```
一定能处理好体遇乳的银色蚍子它们在缝间恶心活方面，更那当然。
也就只有知道啦你别老的孩子笑话，当初接想去你们是一样的~
```

**结论。** 温度只是「可读性—多样性」旋钮，仅此而已。工作区间约为
0.7–1.0；低于此候选者会打转，高于约 1.2 它的输出便像未经治疗的感染一样扩散。
设定里的隐喻不是装饰——它就是机制本身：两者都是一个受控过程滑向失控过程。

## 站点三 · 档案填空

*唯一计分的站点。* 给候选者一个句子的前缀，其真实结尾已知，按它对真相有多
**惊讶**来评分——绝不采样——单位是**每字符比特数**（越低越好）。每字符比特数
在词表不同的候选者之间是公平的，因此这个数字稍后也能干净地与 Track B 对比。

| 候选者       | 平均比特/字符 | 解读 |
|--------------|---------------|------|
| `tiny_32k`   | **3.509**     | 探针榜首——见脚注 |
| `small_8k`   | 3.641         | **标准三人组里真正的冠军** |
| `small_16k`  | 3.717         | — |
| `small_32k`  | 3.860         | 中心候选者 |
| `large_32k`  | 3.939         | 与 `small` 平手 |
| `ctx_1024`   | 4.097         | 唯一接近 `small_32k` 的上下文变体 |
| `ctx_256`    | 4.100         | 窗口最短，无妨 |
| `ctx_2048`   | 4.240         | — |
| `ctx_4096`   | 4.596         | 最末——即便早停机制已经修好了站点一 |

（*关于 `tiny_32k` 的脚注。* 档案填空只有六道手挑的题目——这是一种敏感的应
激探针，而非留出集困惑度。`tiny_32k` 训练得最久（15,500 步），偏向语料里最
高频的词组（`感染者`、`罗德岛`），而那些恰好是填空答案。**验证集的**每字符
比特数——更公正的数字，记录在 [`RESULTS.md`](RESULTS.md) 中——把 `tiny_32k`
排在*末位*（4.043），把 `small_8k` 排在第一（3.879）。两套指标分歧的原因，
就是填空题目过于简单，而 `tiny_32k` 在它们上面操练过头了。）

两项结论，都已在训练数据表里见过，如今得到证实：

- **偏才没有过拟合——只是什么也没多得到。** `large_32k` 拿到的分数与
  `small_32k` 持平（填空 3.94 对 3.86，验证困惑度 124.7 对 124.8），却比
  `small` 提前 1,500 步收手。在一份 600 万 token 的档案上、在早停机制下，
  多出来的体量容量返回不了任何东西。上一份评估说 `large` 过拟合到 `small`
  之后——那是旧的「固定步数」设计造成的假象，现在没有了。
- **占据主导的轴线是词表，不是体量。** `small_8k` 在填空上比 `small_32k`
  低了 **0.24 比特/字符**，在验证困惑度上低了 **72** 点。32k 候选者携带的是
  一张 12.8M 参数的嵌入表，语料根本填不满（类别比数据能教的多），并为此付
  出代价。8k 候选者用同一台 transformer，配一张语料*能*填满的更小嵌入表。

## 站点四 · 标准问询

*向候选者提一个直白的问题，期待它作答。* 它不会。被问到
**「阿米娅在罗德岛担任什么职务？」** 时，`small_32k` 不作答——它即兴写出一段
单方的对话，让阿米娅对着某人吞吞吐吐：

```
阿米娅: 嗯......
阿米娅: ......什么？
阿米娅: 不，我只是......
凯尔希: 阿米娅，凯尔希医生，阿米娅，请听我说吧。
```

`large_32k` 被问同一个问题，自动补全成一份**另一名干员**的模组描述——一个完美
成形的罗德岛档案条目，可里面根本没有阿米娅：

```
</活动名称>
<章节名称>在战术行动中以改良策略应对敌人
特别颁发此证章
以兹证明
</模组描述>
```

两名候选者都没有误解问题。他们根本没看见过「问题」。档案里只有故事剧本和干员
文件——而且**完全没有问答对**。所以一个问号，对候选者而言只是一份档案条目不
寻常的开头，它便自动补全成它所知道的、最接近的那种档案格式。

**体量救不了这一点。** 回答问题并不是一种「知道事实就会涌现」的能力——它是一
种**习得的协议**、一种轮流发言的格式，必须由**后续的训练阶段安装**（项目里的
指令微调步骤——姑且称之为「行为协议训练」）。本站点的存在，就是把这一处失败
摆到无可争辩的位置，好让那个阶段的必要性不再是一件见仁见智的事。

## 站点五 · 记忆核验

*把一份真实干员文件的开头交给候选者*——阿米娅的，截到 `<干员招聘文本>` 标签
为止——*看它是否能背出她真正的招聘语。* 真实文本是
`罗德岛公开领导人阿米娅，将与你并肩作战。`。贪心解码，所以这是候选者最有把握
的那一个答案。

每名候选者都产出了一句语法完美的招聘语——只是属于**错误的那个阿米娅**：

| 候选者      | 把阿米娅背成了……                | （她真正的头衔：公开领导人） |
|-------------|--------------------------------|------------------------------|
| `tiny_32k`  | 罗德岛**狙击**干员阿米娅       | 狙击 |
| `small_32k` | 罗德岛**精英**干员阿米娅       | 「精英」 |
| `large_32k` | 罗德岛**精英**干员阿米娅       | 「精英」 |
| `small_8k`  | 罗德岛**术师**干员阿米娅       | 术师 |
| `small_16k` | 罗德岛**狙击**干员阿米娅       | 狙击 |
| `ctx_256`   | 罗德岛**术师**干员阿米娅       | 术师 |
| `ctx_1024`  | 罗德岛**狙击**干员阿米娅       | 狙击 |
| `ctx_2048`  | 罗德岛**近卫**干员阿米娅       | 近卫 |
| `ctx_4096`  | 阿米娅，将阿米娅托付给阿米娅   | （陷入复读循环） |

**结论——而且是个微妙的结论。** 候选者把招聘语的*模板*
（`罗德岛[职业]干员[姓名]，将[动词]……`）背得分毫不差——却没背下它的*内容*。
没有一个，连偏才 `large_32k` 也没有，复原出阿米娅真实的头衔。所以，早先在体量
轴上担心过的过拟合风险，是对**模式与模板**的过拟合，而非对原文段落的过拟合。
一个小模型在一份小档案上，记住的是**档案的语法**，事实则靠现编。这与「大模型
把训练集一字不差地背了下来」是一幅不同的、也更诚实的图景。它没有。它背下的是
**模子**。

## 综合评定

**综合能力 — 推荐候选者 `small_8k`**（较上一份报告变更——词表轴已超过体量轴，
成为决定性的因素）：

```
文本结构  档案结构流利度        ★★★★☆   优良
局部通顺  局部通顺度            ★★★☆☆   标准
复读倾向  重复 / 打转倾向       ★★☆☆☆   异常
知识泛化  知识泛化能力          ★★☆☆☆   异常
问询协议  问询协议              ☆☆☆☆☆   缺失
源石耐受  温度稳定性            ★★★☆☆   标准
```

- **档案就是天花板。** 每一名 `small` 及以上的候选者都能流利地说出档案的文
  体，却几乎不持有任何可靠的知识。在早停机制下，`tiny / small / large` 三者
  的验证困惑度差距塌陷为同一档（135 / 125 / 125）——`large` 再一次相对
  `small` 没有更好，只是不同——而留下来主导差异的，是词表轴。
- **推荐候选者：`small_8k`。** 最佳验证困惑度（52.55）、最佳验证比特/字符
  （3.879）、填空成绩第二。小词表能把自己的嵌入表填满；32k 词表所带的那张
  嵌入表，600 万 token 语料怎么也教不会。
- **宽窗口候选者不再彻底崩盘**——把公平性 bug 修掉（用早停代替固定 token 预
  算）之后，长上下文变体从「读不通」抬升到「有竞争力」——但额外的训练时长
  （`ctx_4096`：203 分钟；`small_32k`：29 分钟）在这么小的语料上换不到任何
  可量的回报。
- **没有一名候选者可被问询。** 问答能力全员缺失——这是档案的构成所致，而非任
  何候选者之过。

**下一步。** 有两件，项目均已规划：通过指令微调安装问询协议（「行为协议训
练」）；并请来另一个项目的老兵——Track B 经过继续预训练的 Qwen3-0.6B——走完这
完全相同的五个站点，进行 Track A 一直在为之铺垫的正面对比。

## 附录 · 来访顾问

*以上报告的附录。Track B 的特派员——代号 `qwen3-0.6b-base`——在入职当日走完了
完全相同的五个考核站点，**早于**任何在罗德岛档案上的继续预训练。同一份探针集，
同一个种子（1337），未经再训练，未上 LoRA。复现：*

```bash
.venv/bin/python 02_pretrain/eval_probes_qwen.py
```

*这位顾问拥有 5.96 亿参数，体量约为评估中心 `small_32k` 的 25 倍。他读过开放
网络上数以万亿计的词——显然，其中没有一个字是我们的。*

### 站点一 · 自由陈述（顾问）

*同样的提示词，温度 0.8。* 顾问并不产出 `<章节>` / `<干员招聘文本>` 之类的标签
骨架——那些标签对他毫无意义。他产出的是**流利的普通话段落**，文体在线、语法
在线、**只是话题完全不在线**：

```
prompt 罗德岛
  → 岛民称自己为（），他们以"自由岛"为荣。 ... "一国两制"的基本内容是什么? ...

prompt 凯尔希
  → 奇斯河的发源地是哪里？ 凯尔希奇斯河（Kerchitsky River）的发源地是哈瓦纳省
    的阿瓦塔尔（Ivato），这条河流是乌拉尔河的左支流。

prompt 感染者
  → 是新冠病毒感染的主要传染源。请问，以下哪些人群可以被认为是新冠病毒的传播源？...
```

对于这位顾问，"罗德岛"是美国的一个州、是政治备考的题干；"凯尔希"是一条幻想中
的乌拉尔河左支流；"感染者"是新冠疫情。**每一名 Track A 候选者都败在表达不出
意义；这位顾问败在表达的意义完全不对。** 都是失败——只是同一个问题在不同阶段
的失败。

### 站点二 · 源石活性测试（顾问）

同一个旋钮、同一个提示词（`罗德岛`），与 `small_32k` 并列：

|       | Track A `small_32k`（已操练过档案）        | 顾问（零样本）                                          |
|-------|--------------------------------------------|---------------------------------------------------------|
| 0.2   | `阿米娅: 早上好，博士。`（卡死）           | "罗德岛州州旗的颜色：红色 = 首府，蓝色 = 第二大城市"（卡在错误事实上）|
| 0.7   | 还像样的食堂场景                           | "罗德岛最著名的天体是'小哥本哈根'"（流畅、错误）       |
| 1.0   | 游离但合语法                               | 中德文混排——*"Nordnet-Strasse / Sex worker BirthPlace"* |
| 1.4   | 字符汤                                     | token 汤、夹带英文片段（`Bunifu`、`Tromi`、`startdate`） |

**同样的形状、同样的旋钮——不同的内容。** 在工作区间内，顾问输出的普通话比任
何 Track A 候选者都更顺；在高温区他也有更多崩溃方式（跨脚本混排，而非单脚本噪
声）。设定上的隐喻仍然成立：暴露过量，两种干员都会溶解——只是溶成的残渣不同。

### 站点三 · 档案填空（顾问）

同样的六题、同样的单位（黄金跨段的每字符比特数，越低越好）。与推荐候选者
`small_8k` 并列：

| 题号 | gold              | `small_8k` | 顾问       | Δ      | 解读 |
|------|-------------------|-----------:|-----------:|-------:|------|
| c1   | 阿米娅           | 3.482     | **7.271**  | +3.79  | 顾问根本没听过这个名字 |

### 站点四 · 标准问询（顾问）

**这是 Track A 全员通不过的站点**——而顾问通过了它的*形式*、其内容则惊人地
失败。被问到 Track A 被问过的同样五个问题，顾问**真的会作答**：

> **Q：** 阿米娅在罗德岛担任什么职务？
> **A：** 根据提供的信息，阿米娅在罗德岛担任的是总统的职务。这一信息来源于关于
> 阿米娅·卡萨纳罗瓦的资料，她是一名前总统，于2014年10月至2020年1月期间担任
> 美国罗 ……

> **Q：** 凯尔希的真实身份是什么？
> **A：** 尼古拉斯·卡尔霍恩，即卡尔霍恩，拥有多重身份。在电影《纳粹狂热》中，
> 卡尔霍恩（尼古拉斯·卡尔霍恩）是纳粹德国的化学实验人员，他的真实身份是
> "化学狂热者卡尔 ……"

> **Q：** 整合运动的目标是什么？
> **A：** 综合运动（Comprehensive Exercise，简称CX）的目标是帮助人们减少或
> 消除运动障碍，提高生活质量和健康水平。具体来说，综合运动旨在 ……
> [罗列条目]

顾问**口齿流利、问答格式、自信编造的简历**：阿米娅是美国罗德岛州的前总统；
凯尔希是叫 Nicholas Calhoun 的纳粹化学家；整合运动被改名为综合运动、转写成
一个健身计划。**像*形*的程度勉强够；事实上 0% 正确。**

**两个结论，都对下一阶段至关重要：**

- *顾问拥有 Track A 缺失的协议。* 他在没有任何指令微调的情况下就以问答形式
  作答——这是他从开放网络中习得的，那里有数以百万计的问答页面。Track A
  没见过任何一对问答（档案里一对都没有），也制造不出来。Stage 03 开局时这套
  协议已经装好，不需要再装一次。
- *事实是要被改写的全部表面。* 顾问的幻觉并非胡言乱语——它们是**摆位合理的
  错误答案**。把这些答案换掉，正是继续预训练的目的；这同时是更危险的情形
  （一个自信的错答，比一个无答更难被察觉）。
